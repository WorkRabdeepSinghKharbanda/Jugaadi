Next.js (App Router) trilingual marketing site (en at `/`, `/hi`, `/hinglish`) with Markdown-backed content (`website/content/{landing,feature,alternative,blog}` via `src/lib/content.ts`) and SEO surfaces (`robots.ts`, `sitemap.ts`, `llms.txt/route.ts`, generated `opengraph-image.tsx`) built from the same data. Per-locale root layouts (`(en)`, `hi`, `hinglish`) set `<html lang>` (`en`, `hi`, `hi-Latn`). Every page gets a self-referencing canonical, hreflang (`en`/`hi`/`hi-Latn`/`x-default`) and OG/Twitter tags via `src/lib/seo.ts`; JSON-LD (Organization, WebSite, Breadcrumb, FAQ, BlogPosting, SoftwareApplication) lives in `src/lib/jsonld.ts`. Feature slug is `book-instantly` (old `hire-instantly` URLs 308-redirect in `next.config.ts`). `/privacy` is a real policy (indexable, in the sitemap, contact rabdeepsinghkharbanda29@gmail.com, documents the data the app actually collects — update it when data practices change); `/delete-account` is the public account-deletion instructions page (Play Console's required deletion URL; mirrors privacy: erased vs kept, in-app path Profile -> Delete account, email fallback). `/terms` is a real plain-language terms page (indexable, in the sitemap, same contact email). Branded 404 via per-locale `not-found.tsx` plus `global-not-found.tsx` (experimental flag). Copy avoids job-board wording (task/respond/book/choose) for payment-provider review. Visual layer is a component design system (`website/src/components/ui/`, tokens in `src/styles/tokens.css`, styles in `ui/ui.css`; see `.claude/docs/DESIGN-SYSTEM.md`): Header/Footer/Hero/Steps/FeatureGrid/PricingCards/Faq/CtaBand/Toc/LegalPage/DataTable etc. render every page type in all three locales; `npm run check` (website/scripts/check-seo.mjs) verifies SEO basics and banned job-board words for every sitemap URL. Deployed to Vercel project `jugaadi` (`jugaadi.vercel.app`).
