## Response se hiring tak, bina kisi middleman ke

Batao aapko kya chahiye — skill, dates, roughly location, optional daily wage — aur matching paas ke workers respond kar sakte hain. Aap dekhte ho kisne respond kiya (distance se sorted, unke verification status ke saath), aur jise chaho hire karte ho.

## Kya automatically hota hai

Jaise hi aap hire karte ho, us task par respond karne waale baaki sabhi automatically clear ho jaate hain — ek-ek karke manually reject nahi karna padta. Task "booked" status mein chali jaati hai, aur worker ka phone number dikhta hai taaki aap start time aur location directly coordinate kar sako.

## Loop close karna

Kaam poora hone par, task ko complete mark karo. Yehi poora lifecycle hai: open → booked → completed (ya cancelled, agar wapas leni ho). Abhi koi rating nahi, koi chat nahi, koi in-app payment nahi — bas kisi ko jaldi book karaane laayak kaafi.
