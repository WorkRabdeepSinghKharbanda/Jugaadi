## What "verified" means right now

Jugaadi is piloting in a single city, and worker verification reflects that scale honestly: an admin manually confirms a worker's identity — by phone or in person — and flips a verified flag on their profile. It's a basic trust signal, not a police check or automated KYC system.

## Why manual, not automated

At pilot volume, a human check is faster to set up and more accurate than wiring in a third-party verification API nobody's tested yet. The tradeoff is explicit: this scales to the admin's own bandwidth, not to thousands of workers — that's a deliberate choice for the pilot stage, revisited if and when volume demands it.

## Where you see it

The verified badge shows up when an owner reviews who's responded to a posted task, next to each worker's name — so the hiring decision factors in verification alongside distance and whatever else the owner wants to weigh.
