## Abhi "verified" ka matlab kya hai

Jugaadi ek single city mein pilot kar raha hai, aur worker verification isi scale ko honestly dikhata hai: ek admin manually worker ki identity confirm karta hai — phone ya in-person — aur unki profile par verified flag lagata hai. Yeh ek basic trust signal hai, police check ya automated KYC system nahi.

## Manual kyun, automated kyun nahi

Pilot volume par, ek human check kisi untested third-party verification API ko wire karne se zyada fast aur accurate hai. Tradeoff clear hai: yeh admin ki apni bandwidth tak scale karta hai, hazaaron workers tak nahi — yeh pilot stage ke liye ek jaanbujhkar choice hai, jab volume isse demand karega tab dobara dekha jaayega.

## Yeh kahan dikhta hai

Jab koi owner posted task par respond karne waalon ko review karta hai, tab har worker ke naam ke paas verified badge dikhta hai — taaki hiring decision mein distance aur baaki jo bhi owner weigh karna chahe, uske saath verification bhi shaamil ho.
