# Jugaadi

Marketplace connecting shop owners and households with nearby verified temporary workers for 1 day–1 week gigs.

- `app/` — Flutter mobile app (owner + worker)
- `backend/` — Express API (Render), holds the Supabase service-role key
- `website/` — Next.js landing page + blog (Vercel)
- `supabase/migrations/` — DB schema
